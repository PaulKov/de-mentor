# Сценарии и сборка видео

Файлы `01-*.md` – `10-*.md` содержат видимый текст, примеры и озвучку. Блоки `>` читаются голосом, строки списков становятся видимыми на слайде, код из fenced block остаётся редактируемым в PowerPoint. Оформление следует исходникам [урока Spark](../../../decks/apache-spark-foundations/build_lesson04_pptx.mjs).

Для повторной сборки нужны Node.js с доступным `@oai/artifact-tool`, Python с `edge-tts` и `imageio-ffmpeg`, шрифты Aptos и Consolas. В окружении укажи `NIFI_MEDIA_NODE_MODULES` с каталогом библиотек Node. Озвучка использует сетевой синтез русской речи. Исходники видео содержат только учебный текст.

```sh
node render.mjs /path/to/private-build
python encode.py /path/to/private-build ../artifacts/video
```

Рабочая папка содержит PNG кадров, промежуточные звуковые файлы и черновик презентации. Для выпуска проверяй PowerPoint и длительность аудио, MP4 и SRT для каждой серии. При изменении озвучки начни с пустой рабочей папки, чтобы синтезировать новые аудио и тайминги.
