# Сценарии и сборка видео

В файлах `01-*.md` – `10-*.md` каждый раздел второго уровня соответствует слайду. Список задаёт видимый текст, блок кода остаётся редактируемым в PowerPoint. Каждая строка с `> ` содержит законченную реплику преподавателя. Эта же реплика с авторской пунктуацией попадает в заметки слайда и переключаемые субтитры. Оформление следует [уроку Spark](../../../decks/apache-spark-foundations/build_lesson04_pptx.mjs).

Русская речь синтезируется голосом `ru-RU-DmitryNeural`. В [словаре произношения](pronunciation.json) написание из интерфейса сопоставляется с формой для диктора. Например, в заметках и субтитрах студент видит `SOAPAction`, а голос произносит название по частям. Изменение текста, произношения, голоса или темпа меняет ключ звукового кэша. Остальные реплики можно использовать при повторной сборке.

Для сборки нужны Node.js с `@oai/artifact-tool`, шрифты Aptos и Consolas, Python с пакетами `edge-tts`, `imageio-ffmpeg`, `numpy` и доступ к сетевому синтезу. Проверка файлов дополнительно использует PyAV (`av`). Укажи каталог модулей Node в переменной `NIFI_MEDIA_NODE_MODULES`. Из этой папки выполни команды, подставив путь к рабочему каталогу.

```sh
node render.mjs /path/to/build
python encode.py /path/to/build ../artifacts/video
python verify.py
```

Отрендерованная презентация находится в `/path/to/build/nifi-course-draft.pptx`. Для выпуска скопируй её в `../artifacts/apache-nifi-course.pptx`. При работе над одной серией добавь к команде сборки видео, например, `--episode 03-jolt`. В рабочем каталоге остаются кадры, кэш реплик и промежуточные дорожки.

Сборщик удаляет краевую тишину каждой реплики с запасом для тихих согласных. Длительность кадра согласована с непрерывной звуковой дорожкой урока. Субтитры начинаются у измеренного начала речи и занимают одну или две строки. Если фраза не помещается, сократи или раздели её в сценарии по смыслу.

Проверка читает готовые MP4, находит смену слайдов по изображению и измеряет паузы по декодированному аудио. Она также сверяет текст и время встроенных и внешних субтитров, границы реплик и длительность дорожек. Для оценки ударений и смысловой интонации нужны и сами звуковые примеры.
